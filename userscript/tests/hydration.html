服务端渲染页面：等 hydration 之后再把按钮放进工具栏

B 站视频页由 Vue 在服务端渲染，播放器开始播放之后才 hydrate。hydration 之前往服务端渲染的工具栏里插节点会让它失败， Vue 随后整页重新渲染，页面的 checkBofqi 重建播放器，视频从 0 重播。本页模拟带 data-server-rendered 的根节点： 按钮必须等标记消失后才进入工具栏，而播放器里的还原画面和片头读取不受影响。 需要先跑 cargo test -p vatrix-app --test pipeline 生成 target/tmp/pipeline-intro/low.mp4。
